# docs/

This folder holds screenshots referenced from `README.md`.

## What to add here

Take a few screenshots of ShellSync in action and save them as PNG files with these names:

| Filename | What it shows |
|---|---|
| `screenshot-main.png` | The main window with a connected SSH session, sidebar visible, and file transfer panel |
| `screenshot-rdp-dialog.png` | The New RDP Session dialog |
| `screenshot-smart-paste.png` | The multi-line paste preview dialog with a script queued up |
| `screenshot-themes.png` | The settings dialog showing terminal themes with a custom preset saved |

Only `screenshot-main.png` is referenced by the README right now. If you take more, we can extend the README to include them.

## How to take a good screenshot on Windows

1. Open ShellSync and connect to a session
2. Press `Win + Shift + S` to open the Snipping Tool
3. Select the ShellSync window (or a specific region)
4. Save the image to this folder

Keep them at a reasonable resolution — 1600×1000 or so is plenty. Anything larger just bloats the repo without adding detail.
